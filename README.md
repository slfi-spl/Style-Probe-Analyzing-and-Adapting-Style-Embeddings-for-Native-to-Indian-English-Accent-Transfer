# Style-Probe-Analyzing-and-Adapting-Style-Embeddings-for-Native-to-Indian-English-Accent-Transfer

This repository contains the experimental code used for the paper:

**StyleProbe: Analyzing and Adapting Style Embeddings for Native-to-Indian English Accent Transfer**

## Overview

Neural Text-to-Speech (TTS) systems increasingly rely on style embeddings to represent speech characteristics such as prosody, speaker identity, and acoustic style. StyleTTS2 explicitly separates style into prosodic and acoustic embeddings, providing an opportunity to investigate how accent information is represented within these latent spaces.

This work studies:

1. Whether accent information is encoded in pretrained StyleTTS2 style embeddings.
2. How well different English accents can be separated in the embedding space.
3. Native-to-Indian English accent adaptation using StyleTTS2.
4. The relative contribution of acoustic and prosodic embeddings during accent transfer.

Experiments are conducted using LJSpeech, SPICOR TTS 1.0, and IndicTIMIT datasets.

---

## Main Contributions

### Accent Separability Analysis

We analyze StyleTTS2 style embeddings extracted from:

- LJSpeech
- SPICOR TTS 1.0
- IndicTIMIT

The analysis includes:

- PCA visualization
- t-SNE visualization
- Global silhouette scores
- Pairwise silhouette scores

to investigate whether accent-related information is encoded within pretrained StyleTTS2 style embeddings.

### Accent Adaptation

Two adaptation approaches are studied:

#### Fine-Tuning (FT)

The pretrained StyleTTS2 model is fine-tuned on Indian English speech from the SPICOR LJSP subset.

#### Style Vector Substitution (SVS)

The pretrained StyleTTS2 model remains frozen, while style vectors generated by the fine-tuned diffusion model are substituted during inference.

### Embedding Space Analysis

We compare:

- Full style embeddings
- Acoustic embeddings
- Prosodic embeddings

before and after accent adaptation to determine which component contributes most strongly to accent realization.

## Datasets

### LJSpeech

Single-speaker American English corpus used as the source accent and base StyleTTS2 pretrained model.

### SPICOR TTS 1.0

Indian English speech corpus.

The SPICOR LJSP subset contains parallel prompts aligned with LJSpeech and is used for:

- Fine-tuning
- Accent adaptation
- Evaluation

### IndicTIMIT

Indian English corpus containing speakers influenced by multiple Indian languages:

- Bengali
- Gujarati
- Hindi
- Kannada
- Malayalam
- Marathi
- Odia
- Punjabi
- Tamil
- Telugu

Used for multi-accent embedding analysis.

## Installation

Clone the official StyleTTS2 repository first.

Then place the files from this repository into the corresponding StyleTTS2 directories.

Install dependencies:

```bash
pip install -r requirements.txt
```
## Environment

Experiments were conducted using Python 3.10 and PyTorch 2.x.

The repository contains only the dependencies required by the accompanying scripts. Additional dependencies required by the original StyleTTS2 implementation should be installed separately according to the StyleTTS2 repository instructions.

## Data Preparation

### Create Metadata

```bash
python src/data/create_metadata.py
```

### Generate Phonemized Metadata

```bash
python src/data/make_phonemized_metadata.py
```

### Resample Audio

```bash
python src/data/resample.py
```

---

## Embedding Extraction

Extract StyleTTS2 style embeddings:

```bash
python src/embeddings/extracting_embeddings_interspeech.py
```

The extracted embeddings are used for:

- Accent clustering
- PCA analysis
- t-SNE visualization
- Silhouette score computation

## Training

Fine-tune StyleTTS2 on SPICOR:

```bash
python src/training/train_ft_full_slm.py
```

Configuration:

```text
configs/config_ft_full_slm.yml
```

## Inference

Generate speech using the trained model:

```bash
python src/inference/inference_styletts2_interspeech.py
```

- Mel-Cepstral Distortion (MCD)
- Log-F0 RMSE
- Energy RMSE
- Duration MAD
- Vowel Formant Distance
- PPG-DTW

```text
notebooks/Objective_and_embedding_analysis.ipynb
```
